# Luna Translator Code of Conduct

English · [简体中文](#luna-translator-社区行为准则)

## Participation

Luna Translator welcomes participants of all backgrounds and experience levels. These standards apply to issues, pull requests, code reviews, and other spaces maintained by the project.

- Discuss the work and explain disagreements without personal attacks. Give constructive feedback and allow room for different languages and experience levels.
- Respect consent and privacy. Share recordings, transcripts, and identifying information only when you have permission to make them public.
- Harassment, discriminatory language, threats, impersonation, and retaliation for good-faith reports are unacceptable.

## Reporting and moderation

Use GitHub’s **Report content** menu to report an issue, pull request, or comment to repository admins when that option is available. If you cannot report to the admins, or the report concerns a maintainer, follow [GitHub’s abuse reporting instructions](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) to contact GitHub Support privately. Include relevant links and enough context to review the report. Keep private details out of public issues and comments.

Maintainers review reports using GitHub’s private reporting tools. Depending on the severity and context, they may warn participants, remove content, lock conversations, or restrict participation. Use the [security policy](SECURITY.md) to report software vulnerabilities.

## Luna Translator 社区行为准则

[English](#luna-translator-code-of-conduct) · 简体中文

### 参与与交流

Luna Translator 欢迎不同背景和经验水平的参与者。本准则适用于 Issue、Pull Request、代码审查和项目维护的其他交流空间。

- 围绕问题讨论，说明分歧和理由，避免人身攻击。给出具体建议，尊重他人的语言和经验差异。
- 尊重隐私。公开录音、转写或可识别个人身份的信息前，应取得相关人员的同意。
- 禁止骚扰、歧视性言论、威胁、冒充他人，以及针对善意举报的报复。

### 举报与处理

如 Issue、Pull Request 或评论的 **Report content** 菜单提供向仓库管理员举报的选项，请通过该渠道提交。无法向管理员举报，或举报涉及维护者时，请按 [GitHub 举报说明](https://docs.github.com/zh/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) 私下联系 GitHub Support。请附上相关链接和必要背景，避免在公开 Issue 或评论中披露隐私信息。

维护者通过 GitHub 的私密举报工具处理报告，并根据情节采取提醒、删除内容、锁定讨论或限制参与等措施。软件漏洞请按[安全政策](SECURITY.md)报告。
