# 通话同传

[解决方案索引](../README.md) · [English](README.en.md)

## 当前可用范围

公开社区版提供中英面对面轮流对话，可以验证两个翻译方向和同一设备上的回放。站内远程语音可参考官方产品的多人会议能力。第三方音视频通话、译音回注和手机电话／SIP 由接入方实现，本页给出参考架构。[社区版发布范围](../../docs/open-source-plan.md) · [会议同传](../meeting/README.md)

## 参考架构

1. 通过自己的通话平台分别取得 A 和 B 的原始音轨，在服务端按方向调用同传 API。
2. 把 A 的译音路由给 B，把 B 的译音路由给 A。字幕可随各方向输出一起分发。原声与译音使用独立音轨，避免回注音频再次进入同传。
3. 挂断时先结束两路输入，收齐尾部结果并释放资源。电话客服需要单独的 SIP／媒体网关来处理号码、编解码和通话生命周期。

可以先用[听课示例](../classroom/README.md)验证一路音频进出，再用两段各自授权的录音验证两个翻译方向。这一步覆盖独立翻译流。实际通话还需验收重叠讲话、回声、静音、挂断收尾和并发限制。[同传 v3 文档](https://doc.vuilabs.cn/api-reference/realtime-interpretation/)
