## 当前可用范围

公开仓库可以验证单路音频输入、流式译文和译音输出。Mac 产品侧的 OBS 试点以中文麦克风为输入，向本机 OBS 浏览器源提供英、日、韩字幕。OBS 安装包、真实 OBS 运行和直播平台推流仍需单独验收。公开仓库在这里提供参考链路。[单路 v3 示例](../classroom/README.md)

## 从单路音频接入直播

1. 用随附 WAV 先确认 Go Quickstart 能收到译文，按需要生成译音。
2. 接入方从麦克风、混音台或直播制作系统取得有权处理的主播音轨，转换成 v3 所需的单声道 PCM16。
3. 服务端将译文交给自己的字幕叠加层，由 OBS 或直播制作系统负责画面和推流。若另外提供译音，在独立音轨处理混音和同步。

上线前验证原音与字幕同步、暂停再开播、断流恢复和长直播的会话切换。字幕源测试和平台实际播出分开记录。[同传 v3 音频与事件](https://doc.vuilabs.cn/api-reference/realtime-interpretation/#发送音频与读取结果)
