## 当前可用范围

公开社区版支持用单路麦克风或 WAV 获取字幕和译音，也支持同一设备上的中英轮流对话。官方产品另有多人语音 RTC 会议，可按听众语言分发译音，具体入口取决于使用环境和账号权限。社区版的多人会议入口关闭。[社区版发布范围](../../docs/open-source-plan.md) · [官方产品入口](../../README.md#官方网页版与产品介绍)

## 验证单路流程

1. 启动 Web 社区版，打开「快速开始」。可用[讲座样例 WAV](../classroom/sample-zh.wav)作主讲人音轨。
2. 用默认模拟模式验证字幕、保存与回放流程。需要验证真实翻译时，配置社区版模型服务，或用课堂示例直连国内同传 v3。
3. 记录输入和目标语言、字幕与译音是否正确，以及结束后是否收到末段结果。

[部署指南](../../docs/deployment.md) · [可运行的单路 v3 示例](../classroom/README.md) · [社区版验收范围](../../docs/validation.md)

## 多人会议参考架构

会议系统接收每个发言人的音轨，由自己的服务端将所需音轨送入同传 API，再按听众所选语言分发字幕和译音。保留原声，隔离合成音轨和源音轨，避免译音被再次送入翻译。企业集成需单独验证入会与离会、切换收听语言、长会话和并发容量。[同传 v3 文档](https://doc.vuilabs.cn/api-reference/realtime-interpretation/)
